# Java 8 Features 🚀

A simple, beginner-friendly guide to **Java 8 features** — explained in easy language, with real examples, and practice questions for every topic.

If you ever found Java 8 concepts like Lambda Expressions or Streams confusing, this repo is for you. Every topic is broken down into small, easy-to-digest explanations so you can learn, revise, and practice at your own pace.

---

## 📌 Why this repo?

Java 8 introduced powerful features that changed the way we write Java code. But most tutorials either go too deep too fast, or skip the "why" behind things.

This repo aims to fix that by explaining each concept:
- ✅ In **simple, easy-to-understand language**
- ✅ With **clear code examples**
- ✅ With a short **explanation of what's happening and why**
- ✅ With **practice questions** so you can test yourself

---

## 📚 Topics Covered

| Topic | Description |
|---|---|
| 🔹 Lambda Expressions | What they are, why they exist, and how to write them |
| 🔹 Predefined Functional Interfaces | `Function`, `Predicate`, `Supplier`, `Consumer`, etc. |
| 🔹 Stream API | Filtering, mapping, collecting, and processing data easily |
| 🔹 Method References | Shortcuts for writing cleaner lambda expressions |
| 🔹 *(More topics being added regularly)* | Keep checking back! |

> Each topic above has its **own short `.md` file** inside this repo where you can go and revise that specific concept quickly, without going through everything else.

---

## 🗂️ How the repo is organized

Each folder/file focuses on **one topic only**, so you can jump straight to what you want to learn or revise:

```
Java8Features/
│
├── LambdaExpressions.md
├── FunctionalInterfaces.md
├── StreamAPI.md
├── MethodReferences.md
└── README.md
```

Every topic file follows the same simple structure:
1. **Concept explained in simple terms**
2. **Example code**
3. **Explanation of the example**
4. **Practice questions** to test your understanding
